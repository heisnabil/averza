## 🛠 Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** GSAP + Framer Motion
- **UI Components:** Radix UI, Lucide Icons, MUI Stepper
- **SEO:** Dynamic sitemap, robots.txt, JSON-LD structured data, AEO-optimized FAQs
- **Deployment:** Vercel-ready

## 🚀 Features

- **Animated Hero** — Cinematic geometric shapes with floating background elements
- **Tech Stack Marquee** — Infinite-scroll logo cloud displaying technologies we build with
- **Service Carousel** — Interactive feature carousel showcasing all 8 service categories
- **Process Stepper** — Step-by-step visual guide (Discovery → Planning → Building → Review → Launch)
- **Portfolio Showcase** — Interactive staggered cards highlighting real capability areas
- **Tiered Pricing** — Starter / Growth / Scale plans with WhatsApp CTAs
- **FAQ Accordion** — 12 AEO-optimized questions with FAQPage JSON-LD schema
- **Contact Form** — Full validation, privacy consent, and WhatsApp fallback
- **Cookie Consent** — Glassmorphic GDPR-compliant preferences banner
- **Cinematic Footer** — Magnetic hover buttons, scrolling marquee, and social links
- **Fully Responsive** — Optimized for mobile, tablet, and desktop viewports

## 📦 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev         # http://localhost:3000

# Build for production
npm run build

# Start production server
npm start           # http://localhost:3000
```
