# Infispark Technologies LLP — Landing Page

A high-performance, dark-themed landing page built for **INFISPARK TECHNOLOGIES LLP** — India's premier custom software development & IT solutions agency.

**Live:** [infispark.in](https://www.infispark.in)

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** GSAP + Framer Motion
- **UI Components:** Radix UI, Lucide Icons, MUI Stepper
- **Deployment:** Vercel-ready

## Features

- Animated geometric hero with floating shapes
- Infinite-scroll logo cloud with glass cards
- Interactive feature carousel (8 service categories)
- Step-by-step process stepper
- Staggered testimonials with card physics
- Tiered pricing with WhatsApp/Call CTAs
- Accordion FAQ section
- Full contact form with WhatsApp integration
- Cinematic footer with magnetic buttons & marquee
- Fully responsive — mobile-first design

## Quick Start

```bash
npm install
npm run dev       # Development → http://localhost:3000
npm run build     # Production build
npm start         # Start production server
```

## Project Structure

```
app/              → Next.js App Router pages & layout
components/       → All UI sections (header, hero, footer, etc.)
components/ui/    → Reusable primitives (accordion, carousel, shapes)
public/logos/     → Brand assets & partner logos
```
